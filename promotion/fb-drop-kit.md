# FB Drop Kit — Banting for Beginners + Banting 7 Day Meal Plans

Internal page. Not linked anywhere. Don't share this URL.

Every comment below is ready to copy-paste. Value first, link second. The links carry tracking codes so you can see which comment produced which install.

---

## The rules (read once, save yourself a ban)

1. **Max 2 comments per group per day.** Never paste the whole kit in one sitting — that's spam behaviour and groups/bots detect it.
2. **Check the group's pinned post first.** If links are banned outright, use the "no-link" version noted under each comment (answer in text, put the link only in replies when someone asks).
3. **Don't post the same comment twice in one group.** Each topic goes once. If it gets no traction in a week, reword it — never copy-paste identical text.
4. **Reply to every reply you get.** Threads with replies get shown to more people. This is free reach.
5. **If a comment is deleted, leave the group alone for 3 days.** Don't retry the same link the same day.
6. **Be the helpful person first.** The app pitch only comes where someone asks about apps/tools. Everywhere else, the comment stands alone as a useful answer — the link is a bonus, not the point.

## How the tracking works (30 seconds to understand)

Every link below looks like:

```
https://n8us.github.io/-banting-buddy-landing/questions/is-biltong-banting-friendly/?utm_source=fb-bantingforbeginners&utm_medium=group-comment&utm_campaign=dropkit&utm_content=biltong
```

- `utm_source` = which group (`fb-bantingforbeginners` or `fb-banting7daymealplans`)
- `utm_content` = which comment/topic

When someone opens the link and taps the Play button, the install is attributed to that group + topic in Play Console (Acquisition → Campaigns). If you've set up GoatCounter, you see the *click* within hours — installs lag by a day or two.

**Check after 48h:** Play Console → Acquisition → Campaigns → look for `dropkit`. Also GoatCounter dashboard → Sources → `facebook`.

## Group 1: Banting for Beginners

### Comment 1 — "Is biltong banting friendly?"

Post when: someone asks about biltong, snacks, or protein on the go (or in an existing biltong thread).

```
Yes — plain beef biltong is one of the best banting snacks there is. ~2–4g net carbs per 100g and about 50g protein. The trap is the sweet marinades (honey, BBQ, sweet chilli) — those can hit 12–18g carbs. Always check the ingredients for brown sugar or maltodextrin.

I wrote up the full breakdown with the numbers per 100g and per snack pack here:

```

### Comment 2 — "Where do I start / food list for beginners?"

Post when: someone asks where to start, what to eat, or feels overwhelmed. This is your highest-converting link — the guide page has the app CTA in it.

```
When I started I just focused on three things: meat/fish/eggs, veg that grows above ground, and real fats (butter, ghee, olive oil, avocado). Net carbs under 50g/day is the usual banting target.

### Comment 3 — "Is boerewors banting friendly?"

Post when: someone asks about boerewors, braai meat, or wors brands.

```
It depends on the filler. Traditional pure wors (meat, fat, vinegar, spices) is ~1–3g net carbs per 100g. Commercial wors bulked out with rusk or wheat cereal can be 8–12g per serving. Check the ingredients — if rusk, wheat, or sugar is near the top, skip it.

Full breakdown here:

```

### Comment 5 — "Is banana/fruit allowed?"

Post when: someone asks about bananas, fruit, or sweet cravings.

```
Not on strict days — one medium banana is ~24g net carbs, basically your whole day's budget. Berries are the better option: a quarter cup of strawberries is ~2–3g. Fruit is the thing most people accidentally blow their carbs on.

### Comment 6 — "Snack ideas that aren't biltong?"

Post when: someone asks about snacks, or "what do I snack on between meals".

```
There's more out there than people think — pork crackling (0g carbs), cheese cubes, boiled eggs, macadamias (portion them, ~30g), full-fat yoghurt, and a few packaged options at Woolies/Checkers/PnP that actually pass. Most come in at 0–4g net carbs per serve.

### Comment 8 — "Is peanut butter banting friendly?"

Post when: someone asks about peanut butter, nut butters, or sweet treats.

```
Yes, if it's the natural kind — 2 tablespoons of no-sugar peanut butter is ~3.2g net carbs. The trap is the sweetened jars (some popular SA brands add sugar and hydrogenated oil). Flip it over: if sugar or palm oil is in the first three ingredients, put it back.

### Comment C — "How do I count net carbs?"

Post when: someone is confused about carbs, labels, or fibre subtraction.

```
Formula: net carbs = total carbs − fibre. On South African labels it's easier than that — "Glycaemic Carbohydrate" is already net carbs (fibre is listed separately and already deducted). Just watch for sugar alcohols in "low carb" products — those need subtracting manually.

Full method with SA label examples:
https://n8us.github.io/-banting-buddy-landing/guides/how-to-count-net-carbs/?utm_source=fb-banting7daymealplans&utm_medium=group-comment&utm_campaign=dropkit&utm_content=net-carbs
```

## If links get filtered

Some groups hold first-time links for admin approval, or strip them entirely.

- **Held for approval:** fine — that's the queue you can't control, but it's one-time. Don't repost.
- **Stripped/blocked:** post the answer *without* the link. If someone asks "where did you read that", reply with the link — replies often aren't filtered the same way as top-level comments.
- **Never** try to sneak links past a filter with URL shorteners — that gets accounts flagged.

## After 48 hours — the only decision that matters

Open Play Console → Acquisition → Campaigns.

- **A topic got installs?** Post the next comment in the same *theme* (e.g. if biltong converted, boerewors and snacks are next).
- **A topic got zero clicks on GoatCounter and zero installs?** Kill it. Don't retry.
- **One group clearly outperforming the other?** Shift to 2 comments/day there, 1 every other day on the weak one.

Repeat the cycle: 2 comments per day, measure every 48h, cut the flat ones. The kit has ~14 comments — that's 2 weeks of drops. By the time you run out, the data tells you which 5 to rewrite.
